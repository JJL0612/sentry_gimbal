# 云台板载 IMU 航向与杆臂补偿

## 当前启用的逻辑

后续更新：底盘行进坐标变换已切换为大 yaw 绝对编码器和固定车头零位，不再消费下述 IMU 航向用于行进。本文的板载 IMU 解算、杆臂补偿和 0x0404 发送用于大 yaw 的云台航向闭环及姿态诊断；大 yaw 同时叠加底盘实测角速度前馈，不再要求两块 IMU 建立共同航向原点。

本模块提供的云台诊断方向来自云台达妙开发板的板载 BMI088，通过 SPI 获取原始数据、使用原有板载 EKF 解算。应用层直接读取 `Vector_Euler_Angle[0][0]`（即 `Get_Euler_Angle()[0][0]`）作为 yaw，不再由外置 CAN IMU 的独立 Mahony 解算提供航向，也没有在云台应用层累积 `yaw += gyro * dt`。

板载 IMU 与大 yaw 固定，不随 pitch 转动。用户确认 X 向前、Y 向左、Z 向上，安装在大 yaw 轴的右后方，水平杆臂为：

```
r_x = -0.04360 m
r_y = -0.04996 m
水平长度约 0.06631 m
```

只补偿主要绕竖直 yaw 轴旋转时的水平切向、向心加速度；没有假定与底盘质心等高，也没有实现完整三维质心补偿。原始加速度经原有标定后，先扣除杆臂分量，再归一化进入原有 EKF；原始 getter 保持输出原始标定数据，`Get_Compensated_Accel()` 可查看补偿后数据。

```
f_axis = f_imu - alpha × r - omega × (omega × r)
fx_axis = fx_imu - 0.04996 * alpha_z - 0.04360 * omega_z²
fy_axis = fy_imu + 0.04360 * alpha_z - 0.04996 * omega_z²
fz_axis = fz_imu
```

角速度取板载 IMU 实测 gyro Z，单位 rad/s。只对不同接收时间戳的 gyro 样本做差分，20 ms 一阶滤波，导数限幅 ±200 rad/s²；断流超过 50 ms 不跨空档求导。加速度仍包含重力比力，不能直接当作世界系运动加速度积分。

## 航向与板间传输

- 上电至少 1 s、连续 20 个有效静止样本后记录一次云台航向零点，发送当前板载 EKF yaw 减去该零点的归一化偏移角。
- 摇杆回中、禁用/重新使能不重设零点；普通数据丢失后恢复保留零点。
- 有效性由板载 EKF 状态、原始 gyro/accel 的真实更新时间决定，不用前台调用频率伪造新样本。样本超过 50 ms 无效。
- 若板载 EKF 重新初始化，递增坐标代数，重新等待静止零点；通过原有 0x0404 帧的 zero_generation 字段通知底盘。帧长度和命令 ID 不变。
- 底盘原有策略遇到坐标代数改变会拒绝沿用旧坐标原点；应将云台与底盘车头对齐、保持禁用静止并重启两块板，重新建立共同坐标。
- 外置 CAN3 IMU 可继续轮询作为诊断，但不再提供行进坐标变换的航向，不会自动回退成外置 IMU 来源。
- 底盘仍结合自己的航向完成云台坐标 -> 世界坐标 -> 底盘坐标变换，保留已有短时延迟预测。BMI088 六轴 EKF 的 yaw 仍会漂移，直接读取解算角度并不能获得无漂移的绝对方向。

底盘大 yaw 现使用底盘内置 BMI088 实测角速度做前馈、云台板载 IMU 航向 P/角速度 PI 做反馈，叠加滚轮期望角速度；行进坐标始终由编码器单独决定。
